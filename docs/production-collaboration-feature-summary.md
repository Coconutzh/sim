# 项目生产协作系统阶段性交付说明

本文用于向甲方说明当前版本已经具备的核心功能。内容侧重实际操作能力，不展开技术实现细节。

## 一、整体定位

当前版本已经从普通画布工具扩展为面向制作团队的项目协作平台。系统支持多项目、多工种团队、团队实时画布、任务下发与审核、成果展示、消息提醒，以及基于 Hermes Agent 的智能协作能力。

用户登录后，不再只进入单一 workspace，而是先看到自己参与的项目列表。进入某个项目后，默认进入该项目所属团队的团队画布，个人测试画布与团队画布保持隔离。

## 二、项目首页

首页已具备以下能力：

- 展示当前账号参与的所有项目。
- 支持管理员新建项目。
- 项目卡片可查看项目状态、总 DDL、阶段 DDL、任务统计。
- 项目可手动标记为“已完成”或“未完成”。
- 可维护项目总 DDL 和多个阶段 DDL，例如初稿、联排、终审等。
- 提供两种视图：
  - 项目卡片视图：适合快速进入项目。
  - 项目排期视图：按时间轴查看多个项目和任务节点。
- 排期视图支持前后拖动、放大缩小；相近任务会合并显示，放大后可分开查看。
- 首页提供登录状态展示、退出登录和切换账号入口。

## 三、团队画布与个人画布

当前版本明确区分团队画布和个人画布：

- 进入项目后默认打开团队画布。
- 团队画布用于多人实时在线编辑，是项目工作的主入口。
- 个人画布仅用于个人测试、草稿和实验。
- 个人工作流与团队工作流隔离，避免个人测试内容影响团队正式画布。
- 画布内提供简洁的胶囊导航，包含 Home、Team Canvas、Personal Workflows、项目总览、团队管理等入口。

## 四、团队与权限管理

系统已经支持按项目和工种组织团队：

- 管理员可以创建项目和工种团队。
- 团队可绑定不同工种，例如导演、灯光、音响、舞美等。
- 用户可以被分配到不同项目中的对应团队。
- 普通成员可以邀请其他成员加入自己所在项目组。
- 被邀请用户可接受或拒绝邀请。
- 管理员可以审批、管理团队成员，并移除非受保护成员。
- 团队管理员之间存在保护逻辑，避免普通团队管理员相互误删。

## 五、Copilot Skill 与工种能力卡片

右侧 Copilot 已支持按工种展示不同 Skill 卡片：

- 导演团队可看到偏项目管理和任务拆解的快捷能力。
- 灯光、音响、舞美等工种可看到对应工种的示例能力卡。
- Skill 卡片可快速填充提示词，或打开任务发布、提交任务等操作入口。
- Skill 配置与团队/工种 Profile 关联，后续可以继续扩展更多工种能力。
- 界面文案以中文为主，适合中文团队直接使用。

## 六、Hermes Agent 接入

当前版本已接入 Hermes Agent，用于增强 Copilot 和项目助手能力：

- Copilot 可通过 Hermes Agent 理解当前画布上下文。
- Agent 可以读取画布节点、总结节点关系，并提出画布修改建议。
- 涉及真实改画布的操作会进入确认流程，不是直接无提示写入。
- 已支持多模态输入链路，可处理与图片等附件相关的上下文。
- 已接入 Hermes Memory 能力，配置启用后可沉淀用户、项目和协作经验。
- 系统提供 Hermes 健康检查、工具调用审计和本地联调脚本，方便后续部署与排查。

## 七、生产任务系统

项目总览中已经具备生产任务能力：

- 导演团队可以发布任务给项目内已有工种团队。
- 任务支持标题、说明、DDL、承接团队、依赖任务和附件。
- 任务附件支持链接和本地上传文件。
- 任务可编辑基础信息，例如名称、说明、DDL、承接团队等。
- 修改任务基础信息不会覆盖历史提交版本、聊天记录和审核记录。
- 任务状态覆盖待处理、进行中、已提交、已通过、需修改、已归档。
- 超期任务可要求承接团队提交延期理由。
- 延期理由会保留，并进入后续进度分析依据。

## 八、提交审核与版本历史

任务提交已经支持多种交付形式：

- 可提交画布节点。
- 可提交文字说明。
- 可提交图片、视频、文档等本地文件。
- 提交内容可以下载查看。
- 每次提交都会形成独立版本，不会覆盖旧版本。
- 导演可查看历史提交版本、审核意见和附件。
- 导演可审核通过，也可要求修改。
- 返修后团队可以再次提交新版本，形成完整追溯链路。

## 九、任务内聊天

每个任务都带有任务内聊天：

- 承接团队和导演可围绕具体任务沟通。
- 聊天记录保存在任务下，便于回看上下文。
- 聊天界面支持放大查看。
- 消息区采用类似即时通讯的左右布局，方便区分自己和对方消息。
- 任务聊天会进入消息提醒体系。

## 十、项目总览与成果中心

原 showcase 入口已经调整为项目总览用途：

- 项目总览不再以 mainline 画布展示为核心。
- 当前更像生产看板，包含“成果中心”和“任务进度”两个主要模块。
- 成果中心可发布最终结果，例如优秀文案、灯光参数、音响设置、图片、视频、文档等。
- 成果不强制要求导演审批后才能发布。
- 导演和发布者具备撤回或删除成果的能力。
- 任务进度支持按团队分组查看，也支持全局时间线查看。
- 团队分组支持折叠，适合任务数量较多的项目。

## 十一、通知与 DDL 提醒

系统已提供项目内消息提醒能力：

- 首页和项目内均有自定义消息铃铛。
- 未读任务消息会按任务和工种归类。
- 24 小时内到期的任务会出现 DDL 预警。
- 超期且缺少延期理由的任务会提示补充原因。
- 用户可以单条标记已读，也可以全部已读。
- 团队邀请、任务消息、DDL 风险会进入提醒入口。
- 当前通知结合实时事件和轮询刷新，保证本地使用时能及时更新。

## 十二、项目生产助手

首页排期视图附近已经提供项目生产助手：

- 可分析当前用户可见的所有项目和任务。
- 可判断整体进度是否正常。
- 可识别异常拖延任务、超期任务、待审核积压和缺少延期理由的任务。
- 可结合延期理由说明风险来源。
- 支持普通聊天，不再只回答“进度和阻塞”。
- 可聚焦到某一个具体任务进行追问。
- 聚焦任务时，助手可以看到该任务的历史提交版本和任务聊天记录，从而帮助导演判断问题原因。

## 十三、建议验收流程

建议甲方按以下路径验收当前版本：

1. 管理员登录，创建一个新项目。
2. 在项目中创建导演、灯光、舞美等团队，并邀请测试账号加入。
3. 导演进入项目，确认默认进入团队画布。
4. 导演在项目总览中发布一个任务给灯光或舞美团队。
5. 承接团队登录后查看任务，提交文字、文件或画布节点。
6. 导演查看提交版本，进行通过或要求修改。
7. 双方在任务内聊天，确认消息铃铛和未读提醒正常。
8. 在首页排期视图中查看项目时间轴和 DDL。
9. 使用项目生产助手询问“哪些任务最危险”“某个任务为什么拖延”。
10. 将最终文案、参数或文件发布到成果中心，确认可查看和撤回。

## 十四、当前交付价值

当前版本已经具备一个生产团队可实际试用的基础闭环：

- 项目创建与项目入口。
- 工种团队与用户隔离。
- 团队实时画布。
- Copilot Skill 快捷能力。
- Hermes Agent 智能协作。
- 任务下发、提交、审核、返修。
- 任务聊天与消息提醒。
- 文件上传、下载和版本留存。
- 项目总览、任务进度和成果展示。
- 多项目 DDL 排期与智能进度分析。

这意味着系统已经不只是演示 Demo，而是可以围绕真实制作项目进行小规模团队试运行，并继续向更复杂的排期、权限、资产管理和自动化协作扩展。
